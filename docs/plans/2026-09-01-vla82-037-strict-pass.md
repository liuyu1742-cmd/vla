# VLA82-037 严格 PASS 实施设计

## 权威操作

- 物体：夹子。
- 操作：将夹子从抽屉内抓起并放置到台面。
- 来源：`configs/vla82_full_simulation/operation_specs.json` 对应 `VLA82-037` 条目及其 `operation.json` 溯源。

## 方案选择

采用现有 RoboCasa / MuJoCo 真实接触闭环与专家控制器，不改变任务语义。夹子保留可辨识的双臂夹持外观；抽屉保持正常打开状态，台面为最终支撑面。优先复验当前版本，因为历史轨迹的唯一结构性失败是抓取前右指与抽屉内侧壁接触，而当前代码已有抽屉正面安全入口和水平长轴约束。

若基线仍失败，只调整 VLA82-037 的横向抽屉出生位置或正面入口安全余量，使夹子位于开放槽中部；不绕过接触判定，不瞬移物体，不伪造阶段事件。验证必须包含双指/双垫真实抓取接触、物体离开抽屉、台面真实支撑、松爪后稳定和撤离后保持。

## 验证与交付

1. 先运行现有单元回归与一次完整物理轨迹，取得基线。
2. 若需修改，先增加能复现侧壁碰撞风险的失败测试，再做最小改动并复验。
3. 生成正向、无遮挡的 1280×720 视频，人工查看抓取、搬运、放置、松爪和末态。
4. 将最终 MP4 与判定 JSON 移入 `datasets/VLA82 video`，更新严格 PASS 汇总表。
