# VLA82-041 与 VLA82-051 外观增强实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变既有物理包络和任务语义的条件下，使汤勺、铅笔和开放式实体笔盒具有可辨识外观，并用新严格 PASS 视频与 JSON 替换归档旧文件。

**Architecture:** 外观增强集中在 `assets.py` 的 MJCF 可视几何分支中；碰撞几何、注册包围盒、质量载体和摩擦配置保持原值。自动测试先约束视觉部件和物理不变量，再采集独立新轨迹、生成 720p 视频，最后以精确路径完成受控替换。

**Tech Stack:** Python 3.11、MuJoCo、RoboCasa、robosuite、`unittest`、FFmpeg/ffprobe、PowerShell。

## Global Constraints

- 不导入外部网格，不依赖网络纹理。
- 不改变已验证的碰撞包络、注册尺寸、质量载体、摩擦力或任务场景。
- VLA82-041 保持水平放置方向和单一碰撞体。
- VLA82-051 笔盒顶部保持开放，不缩小内部插入空间。
- 只有 `status=PASS` 且 `predicate_success=true` 的新回合才允许替换。
- 新视频必须为 1280×720、正向无遮挡且可正常解码。
- 旧文件删除仅限 041、051 的四个明确归档路径。
- 当前目录不是 Git 仓库；所有“提交”步骤用测试输出和 SHA-256 快照替代。
