# VLA82-021 密封保鲜盒三指夹持设计

## 目标

使 VLA82-021 在 RoboCasa/MuJoCo 物理仿真中完成真实的抓取、抬起和柜内放置；不得直接写入物体位姿、关节状态或成功标志。

## 已定位的问题

保鲜盒扁平且较宽（最窄外径 120 mm）。默认 Panda 夹爪最大指腹开口仅 86.9 mm，不能包住物体；侧向进入又会使长手指先碰到台面。

## 采用方案

1. 保持真实视频标注对应的“抓取后放入柜内”任务和原始物体资产。
2. 在 PandaOmron 仿真机器人上装配 RoboSuite 官方 `RobotiqThreeFingerGripper`，以三指包络抓取 120 mm 宽的扁平盒体。
3. 用三块指腹的实际位置计算开合轴，使手指沿盒体短边闭合，并沿盒体长边从侧面进入；仅当至少两个物理指腹形成水平对向接触、原生抓持信号成立后，才执行抬起和移动。
4. 在柜内目标区域真实释放，并以接触、抬升、目标区域和释放的严格谓词判定结果。

## 排除方案

- 不放宽抓持判据，不把“接近物体”记为抓取成功。
- 不使用传送、物体位姿写入、关节状态写入或脚本直接置成功。
- 不把源数据视频或合成占位图作为仿真结果证据。

## 验收与证据

单回合只有同时满足下列条件才能写为 PASS：两指腹物理接触、原生抓持成立、物体离开初始支撑面、物体进入柜内目标区且释放。每回合保存 JSON 轨迹与 NPZ 观测/动作；严格 PASS 后从该回合相机观测导出 MP4。
