# VLA82-037 夹子水平放置与快速初始化预检设计

## 目标

修复 VLA82-037 在 RoboCasa `PickPlaceDrawerToCounter` 场景中的初始化失败，使夹子能够以符合真实使用方式的水平姿态放入抽屉，并在不降低严格 PASS 标准的前提下继续真实物理闭环测试。

## 已确认根因

VLA82-037 的模型把夹子长轴放在局部 Z 轴。当前 `reg_bbox` 半尺寸为 `(0.012, 0.012, 0.095)`，因此 RoboCasa 将其视为约 190 mm 高的竖直物体。抽屉重置区域的有效高度不足，`fixture.sample_reset_region()` 连续 50 次拒绝所有候选抽屉，最终抛出 `PlacementError`。本轮因此记录为 `steps=0`，控制器没有开始执行。

## 方案

### 1. 修正自然姿态

仅针对 VLA82-037，把模型的长轴由局部 Z 轴调整到水平轴：

- 可视几何、碰撞几何和 `reg_bbox` 使用同一水平朝向；
- 保持物体总体长度、厚度、质量密度和摩擦参数不变；
- 不通过缩小模型规避空间约束；
- 不在 reset 后写入物体位姿。

修复后的初始姿态代表夹子平放在抽屉内，符合源标注“抽屉到台面放置”的物理语义。

### 2. 快速几何预检

在启动完整仿真前，执行纯几何预检：

- 最长轴必须位于水平面；
- 竖直全尺寸必须小于可用抽屉高度；
- `reg_bbox` 必须完整覆盖可视和碰撞几何；
- 三个轴向尺寸的数值集合仍与 VLA82-037 的权威物体配置一致，仅把最长尺寸从竖直轴置换到水平轴。

预检失败时直接停止该对象，不进入 RoboCasa 的 50 次重载流程。

### 3. 严格物理复测

预检通过后，只运行一次完整 VLA82-037 物理闭环：

1. RoboCasa 正常采样并打开源抽屉；
2. 机械臂接近夹子并形成真实双指接触；
3. 夹子离开抽屉支撑面且运输中不脱落；
4. 夹子移动到台面上方；
5. 夹子由台面稳定承托后机械爪释放并撤离；
6. 严格谓词同时验证动作阶段、接触、位姿变化和最终支撑关系。

只有上述条件全部满足才记录严格 PASS、保留结果视频并更新汇总 Excel。

## 不在本次范围内

- 不修改通用抽屉采样器或 RoboCasa 第三方判定逻辑；
- 不关闭边界检查或有效放置检查；
- 不降低抓取、接触、运输、释放或最终状态阈值；
- 不修改其他 VLA82 物体资产；
- 不因环境成功加载而判定操作成功。

## 测试要求

### 自动测试

- 新增一个先失败的测试，证明旧 VLA82-037 模型长轴为竖直方向且不满足抽屉放置约束；
- 修复后测试确认长轴水平、竖直尺寸降低且物体总体尺寸集合不变；
- 运行现有 VLA82 源资产、场景构建和严格谓词回归测试。

### 仿真验证

- 几何预检必须在数秒内完成；
- 场景必须成功生成非零控制步；
- 若物理操作失败，保留诊断结果但不生成严格 PASS 视频、不更新 PASS 表；
- 若严格 PASS，生成高清无遮挡视频并更新视频路径汇总表。

## 停止条件

模型姿态修复后若快速预检仍失败，则停止完整仿真并重新检查资产边界定义。预检通过但首次完整物理运行失败时，先分析首个真实动作阶段根因，不立即重复运行。
