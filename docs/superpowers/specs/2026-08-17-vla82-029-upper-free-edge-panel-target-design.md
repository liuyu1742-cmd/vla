# VLA82-029 上半部偏自由边门板目标设计

## 1. 目标与证据

受限底盘辅助已成功完成安全抬升：底盘移动 `25.9 mm`，无材料级碰撞，夹爪进入抬升目标 `25 mm` 范围并切换到 `traverse_to_upper_panel`。新的失败发生在水平横移：门板中心预接触目标约为 `x=-1.086 m`，机械手稳定停在约 `x=-1.362 m`，剩余距离约 `0.277 m`。目标过于靠近机器人底盘中心，固定底盘下机械臂无法继续向内收缩。

本轮保留已经验证的自由边绕行、安全抬升和底盘辅助，只将宽门板接触点从水平中心移到上半部偏自由边位置，以缩短横移距离并保持较大的关门力臂。

## 2. 自由边方向

从实时门板 OBB 中识别门板平面内的水平轴。计算该轴正、负两个边缘中心点，选择距离铰链锚点更远的一端作为自由边。自由边方向定义为：

`free_edge_direction = normalize(free_edge - panel_center)`

该计算使用实时门板旋转和铰链位置，不依赖世界 X/Y 正负方向。

## 3. 新接触点

沿门板水平半宽向自由边偏移 `65%`：

`horizontal_offset = 0.65 × panel_half_width × free_edge_direction`

在现有上半部竖直偏移基础上计算：

`panel_face = panel_center + horizontal_offset + 0.45 × panel_half_height × vertical_axis - push_direction × projected_half_thickness`

`panel_precontact = panel_face - push_direction × 0.06 m`

采用 `65%` 的原因：当前门板半宽约 `0.234 m`，目标向自由边偏移约 `0.152 m`，预计世界 X 从约 `-1.086 m` 移至约 `-1.23 m`；同时距自由边仍保留约 `0.082 m`，可容纳紧凑闭合夹爪接触。竖直位置继续高于把手至少 `0.07 m`，顶部余量继续不少于 `0.08 m`。

## 4. 可达性检查

生成路径前必须验证：

- 目标仍位于门板平面内部；
- 到自由边的水平余量不少于 `0.075 m`；
- 高于把手至少 `0.07 m`；
- 顶部余量不少于 `0.08 m`；
- 从抬升点到新预接触点的直线距离不超过 `0.20 m`。

若任一条件不满足，几何函数明确报错，不运行物理仿真。当前场景预计横移距离由约 `0.32 m` 降至约 `0.17–0.18 m`。

## 5. 路径与控制

状态顺序保持不变：

1. 自由边绕行；
2. 正确侧跨面；
3. 受限底盘辅助完成安全抬升；
4. 锁定底盘；
5. 横移到偏自由边预接触点；
6. 沿门板法向贴合宽门板；
7. 形成真实宽门板接触后沿关门切向推送；
8. 接触丢失时只做 `0.006 m` 短距离重新贴合。

横移、贴合和推门阶段不得重新启用底盘。把手和边框接触仍不得触发 `push_close`。

## 6. 组件变更

只扩展现有 `fixture_close_upper_panel_waypoints`：新增铰链锚点和 `horizontal_free_edge_fraction=0.65` 输入，返回 `free_edge_direction`、水平偏移量和边缘余量。现有门板选择、竖直目标、底盘辅助、接触法向控制和严格谓词保持不变。

`DrawerClosePrimitive` 传入实时铰链锚点，使用新的锁存预接触点和表面点，并在轨迹中记录水平目标计算证据。

## 7. 测试策略

通过 TDD 验证：

1. 正、负两个候选边缘中始终选择远离铰链的一端。
2. 目标沿自由边方向偏移恰好为半宽的 `65%`。
3. 剩余边缘余量不少于 `0.075 m`。
4. 门板旋转后自由边方向和目标随 OBB 正确旋转。
5. 把手、顶部和 `0.20 m` 可达性约束不满足时明确失败。
6. 非微波炉任务不受影响。

全部回归通过后执行一轮新鲜 VLA82-029 物理仿真，优先检查横移是否进入 `25 mm` 范围、底盘是否保持固定、是否开始 `seat_upper_panel`，然后再检查宽门板连续接触和铰链闭合。

## 8. 成功与停止条件

阶段成功要求：横移完成、底盘无新增移动、无把手/边框提前碰撞，并进入宽门板贴合阶段。最终严格 PASS 仍要求宽门板连续真实接触、铰链角持续趋近 `0 rad`、达到严格关闭阈值且稳定保持。

若偏自由边目标仍在固定底盘下不可达，不继续提高偏移比例，因为会侵占边缘安全余量；下一步应停止 VLA82-029 本路径，转向其他更容易形成严格 PASS 的物体操作，而不是继续无意义重试。
