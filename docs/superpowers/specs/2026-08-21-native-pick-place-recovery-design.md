# 原生抓取—放置恢复设计

## 目标

在不写入 MuJoCo 状态、不降低严格 PASS 判定、且不影响现有 15 项严格 PASS 的前提下，提高剩余原生物体抓取—放置任务的真实物理闭环成功率。

## 已确认问题

1. 多个失败项停留在 `reach_base`：随机厨房重置使移动底盘被无关柜体阻挡，未能进入手臂工作空间。
2. 夹爪已经接近物体的任务常在 `approach` 状态耗尽步数：控制目标用腕部原点而非双指接触中心，且没有按实时距离收敛确认。
3. 窄抽屉与门把手任务属于独立的几何可达性问题，不纳入本阶段的通用修复范围。

## 方案

仅对“原生物体、非抽屉源、非家具关节”的抓取—放置请求启用一套恢复配置：

- 在重置前将底盘锚定在 RoboCasa 已采样的源物体所属台面/柜体外侧，不改变任何物体或家具位姿。
- 以实时双指中心而不是腕部原点计算接近距离；只有双指中心到达预抓取点后才进入下降与闭合。
- 所有后续阶段继续依赖 MuJoCo 接触、物体位移、目标接触及稳定帧判定；恢复配置不创建通过状态。

## 验收

- 新增单元测试覆盖：源物体锚定、双指中心接近转换与抽屉/家具任务排除。
- VLA82-012、013、056 中至少选择一个原生物体完成一次真实物理闭环；未达到严格判定不得写入 Excel。
- 现有严格 PASS 任务的回归测试通过。
