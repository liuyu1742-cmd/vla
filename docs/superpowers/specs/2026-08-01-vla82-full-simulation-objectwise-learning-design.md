# VLA82 中期 8 类 60 物体完整仿真逐物体学习设计

## 1. 目标

在不引入真实机械臂的前提下，使用 RoboCasa/MuJoCo 完整仿真机械臂、家庭场景和可辨识物体资产，完成 8 类家政任务与 60 种物体的逐物体操作学习、独立视觉识别和物理闭环复现。

最终验收必须达到：

- 8 类任务通过 8/8；
- 60 种物体通过 60/60；
- 每物体 10 个未参与训练的固定验收种子，共 600 次；
- 视觉 Top-1 识别 600/600；
- 仿真物理操作 600/600；
- 总成功率 100%；
- 每项训练、模型、轨迹、视频和判定证据完整可追溯。

现有抽象三轴夹爪、简化几何体和脚本监督轨迹只保留为历史预验证，不计入本设计的最终验收。

## 2. 权威范围与操作语义

权威台账：

`C:\OpenVLA-Simulator\outputs\midterm_testing_vla82\VLA82范围内_中期8类60物体测试执行台账_真实闭环更新.xlsx`

固定范围为该工作簿“60种物体”工作表 A2:T61 的 60 个选择 ID，不增删、不替换。

每个物体的操作语义按以下优先级确定：

1. 对应数据目录中的 `operation.json`；
2. 对应数据目录中的 `instruction.json`；
3. 台账“真实视频标注”列；
4. 台账“表内操作标签”仅作来源上下文，不得覆盖真实视频标注。

如果各来源不一致，必须生成差异记录；以原始 JSON 和真实视频内容为准更新执行规范。不得根据物体名称自行套用通用抓取动作。

## 3. 已选方案与备选方案

### 3.1 采用：共享主干与 60 个独立技能适配器

- 共享视觉编码器、机器人控制接口和训练框架；
- 每个物体分别采集示范、训练轻量技能适配器；
- 每个物体保存独立权重、训练日志、数据清单、验证报告和 SHA256；
- 独立 60 类视觉识别器不接收目标物体名称；
- 技能适配器预测阶段、目标位置或关节目标；
- 标准 IK、动作限幅、碰撞保护负责执行，不提供逐物体预编排完整轨迹。

该方案在保留逐物体学习证据的同时，共享计算量和基础能力，最适合快速稳定完成 60/60。

### 3.2 不采用：单一 60 类多任务策略

训练和部署较简单，但难以形成 60 份独立学习证据，类别间相互干扰也会降低 100% 验收的可控性。

### 3.3 不采用：60 个完整独立大模型

独立性最强，但训练、显存、存储和调试成本过高；相较轻量适配器没有必要的验收收益。

## 4. 系统架构

完整数据流如下：

```text
公开人体示范视频
  → 人体/手部—物体交互与阶段解析
  → 8 类任务 Skill IR
  → 按真实视频标注生成 60 项操作规范
  → RoboCasa 完整机械臂专家示范
  → 共享视觉主干
  → 60 个物体分别训练技能适配器
  → 无目标名称提示的 60 类视觉识别
  → 技能阶段与目标预测
  → 标准 IK / 安全控制器
  → RoboCasa / MuJoCo 物理执行
  → 操作专用成功谓词
  → 视频、首末帧、接触帧、轨迹和报告
```

系统划分为六个边界清晰的组件：

1. **操作规范编译器**：读取台账和原始标注，将自然语言操作编译为阶段、有向条件和物理谓词。
2. **资产与场景解析器**：加载官方资产或构建同类可辨识资产，配置完整机械臂、家具、相机、碰撞体和关节。
3. **专家示范采集器**：生成成功轨迹，保存 RGB、机器人状态、夹爪状态、动作、接触和成功标签。
4. **逐物体训练器**：共享主干并训练 60 个独立适配器，执行验证和 DAgger 增量学习。
5. **视觉识别器**：在完整 60 类候选中从图像独立输出 Top-1 类别和置信度。
6. **验收运行器**：组合识别、适配器、IK 和物理谓词，执行 600 次测试并生成不可伪造的证据清单。

## 5. 仿真资产与完整机械臂

### 5.1 机械臂

- 使用 RoboCasa/robosuite 支持的完整机械臂、末端执行器和机器人相机；
- 视频必须清楚显示机械臂本体、夹爪、目标物体和操作区域；
- 所有动作通过仿真控制接口进入 MuJoCo，不允许直接修改物体最终位置或设备最终关节状态；
- IK、碰撞保护、关节限位和动作限幅属于标准低层控制器，可以使用；
- 标准控制器不得包含某一选择 ID 的完整硬编码轨迹。

### 5.2 物体

- 优先使用 RoboCasa 官方同类网格、材质和家具资产；
- 官方库没有的类别，构建同类可辨识仿真资产，包含类别名称、合理尺寸、质量、材质、碰撞体、抓取点或可操作关节；
- 资产必须通过加载、相机可见性、碰撞、质量、关节范围和语义一致性检查；
- 功能代理、错误类别和仅写入名称的几何体不得计入最终通过；
- 真实标注涉及多个物体时，场景必须加载所有被操作对象，而不是只加载台账标题物体。

## 6. 逐物体示范和学习

每个选择 ID 独立执行以下流程：

1. 读取真实视频标注并生成操作规范；
2. 在完整仿真场景中采集初始 6 条专家示范，随机化物体位置、朝向、相机和背景；
3. 保存 RGB、深度或几何辅助信息、机器人状态、夹爪状态、动作、接触、阶段和成功标签；
4. 用共享视觉主干和该物体独立适配器学习当前阶段、目标位姿或设备关节目标；
5. 保存独立数据清单、训练曲线、验证结果、权重文件和 SHA256；
6. 在未参与训练的验证场景运行；
7. 若未达到 100%，按失败分布生成 4000 以上的新修复种子，收集 DAgger 示范并增量训练；种子 1000—1009 的验收轨迹不得进入训练集；
8. 验证通过后进入固定 10 种子验收。

60 个适配器之间可以共享视觉主干，但不得共享或复制一份适配器权重后伪装成独立学习结果。

## 7. 操作类型与物理成功谓词

所有谓词由真实视频标注编译，至少覆盖以下操作族。

### 7.1 抓取与搬运

- 夹爪与目标物体发生有效接触并闭合；
- 目标物体离开初始支撑面；
- 物体到达标注目标区域；
- 释放后保持稳定，不依赖夹爪继续支撑。

### 7.2 投放与丢弃

- 物体被抓取并移动至垃圾桶或指定容器上方；
- 释放后物体进入目标容器有效体积；
- 最终状态不再由夹爪持有，且保持在容器内。

### 7.3 擦拭与刷洗

- 机械臂抓持正确清洁工具；
- 工具与目标表面维持有效接触力和最短持续时间；
- 擦拭或刷洗轨迹覆盖标注区域；
- 污渍掩膜或污染值下降至操作规范阈值以下；
- 若标注要求放回工具，还必须完成稳定放回。

### 7.4 喷洒

- 喷嘴朝向目标表面；
- 夹爪或末端触发喷头行程；
- 喷洒粒子或覆盖掩膜到达指定区域并满足覆盖阈值；
- 标注包含取放时，必须同时通过取放谓词。

### 7.5 放入与插入

- 目标物体主体进入抽屉、橱柜、杯、笔盒、纸箱、收纳盒或收纳箱的有效体积；
- 物体不能只停在容器边缘或旁边；
- 释放后在容器中保持稳定。

### 7.6 叠放

- 上下物体形成稳定支撑接触；
- 水平偏差、姿态偏差和重叠面积满足操作规范；
- 释放后保持规定稳定时间。

### 7.7 相邻、并排和分区摆放

- 满足“键盘旁”“鼠标旁”“床边并排”“用品分区”等指定空间关系；
- 同时检查距离、方向、相对顺序、区域边界和物体间碰撞；
- 多物体标注必须逐一完成全部关系。

### 7.8 门、盖和铰链开合

- 夹爪或末端接触把手或有效操作区域；
- 铰链关节因机械接触实际运动；
- 最终关节角达到打开、关闭或合盖阈值。

### 7.9 抽屉、托盘和层架推拉

- 接触把手或可操作边缘；
- 滑动关节沿正确方向运动；
- 最终关节位移达到完全推入、拉出或关闭阈值。

### 7.10 旋钮操作

- 机械臂接触并约束旋钮；
- 旋钮关节产生正确方向和幅度的角位移；
- 设备控制状态与真实标注目标一致。

### 7.11 按压、出液与设备按钮

- 末端与按钮、泵头或控制部件接触；
- 按压行程和保持时间达到阈值；
- 设备状态改变，或出液量达到规定值；
- 标注包含摆放时还必须通过对应摆放谓词。

### 7.12 复合和多物体操作

- 按真实标注顺序执行所有阶段；
- 每个阶段均保存开始、接触、结束和局部谓词结果；
- 最终通过要求全部阶段为真；
- 不得只检查最后位置，也不得省略六本书、铅笔与两支笔、书籍与凉鞋等标注对象。

## 8. 独立视觉识别

- 训练或校准一个完整 60 类候选识别器；
- 输入仅为机器人相机图像，不提供当前期望物体名称、选择 ID 或答案标签；
- 输出 Top-1 类别、置信度、检测框或掩膜；
- 训练视角和验收视角必须分离；
- 每个验收种子均执行识别，共 600 次；
- 任何一次 Top-1 错误都视为该种子失败；
- 识别失败只能通过数据增强、标注修复和重新训练解决，禁止用期望答案覆盖预测。

## 9. 验收流程

### 9.1 8 类任务

每类必须同时具备：

- 可追溯人体示范视频；
- 人体、手部和物体交互解析结果；
- 从示范学习得到的任务级 Skill IR；
- 至少一个对应物体的独立技能适配器；
- 完整仿真机械臂执行视频；
- 物理操作成功谓词为真。

合格条件为 8/8。

### 9.2 60 种物体

每个物体必须具备：

- 真实视频标注一致的操作规范；
- 独立专家示范数据；
- 独立训练日志和适配器权重；
- 独立视觉识别结果；
- 完整机械臂轨迹；
- 对应操作的物理成功谓词；
- 视频、首帧、关键接触帧和末帧；
- 数据、标注、模型和证据 SHA256。

合格条件为 60/60。

### 9.3 600 次固定种子验收

- 每个物体使用 10 个固定、未参与训练和验证的验收种子；
- 每次必须识别正确、真实调用该物体适配器、完整机械臂实际运动且物理谓词成功；
- 10 次中任何一次失败，该物体即不合格；
- 失败后使用 4000 以上的新修复种子增加 DAgger 数据并重训，然后重新执行该物体全部 10 个验收种子，禁止把 1000—1009 的验收轨迹加入训练，也禁止只补跑失败种子；
- 最终视觉识别必须为 600/600，物理操作必须为 600/600。

## 10. 证据结构

最终输出根目录：

`C:\OpenVLA-Simulator\outputs\midterm_testing_vla82\full_simulation_objectwise_8x60`

每个选择 ID 目录至少包含：

- `operation_spec.json`：原始标注、解析阶段和物理谓词；
- `annotation_diff.json`：台账、JSON 和视频语义差异；
- `demonstrations/manifest.json`：专家示范及哈希；
- `training/metrics.json`：训练与验证指标；
- `training/adapter.pt`：独立适配器权重；
- `training/adapter.sha256`：权重指纹；
- `recognition/`：600 次中的本物体 10 次识别结果和图像；
- `rollouts/seed-*/`：轨迹、视频、首帧、接触帧、末帧和谓词；
- `representative.mp4`：该物体高质量代表视频；
- `report.json`：该物体的 10/10 总结。

根目录还必须包含：

- `task_learning_8/`：8 类人体示范、Skill IR 和代表复现；
- `manifest.json`：8/8、60/60、600/600 严格门禁；
- `evidence_contact_sheet.png`：60 物体首帧、接触帧和末帧总览；
- `acceptance_matrix.xlsx`：训练、识别、执行、证据和最终状态矩阵；
- `reproduction_commands.txt`：环境、模型、参数和复现命令。

600 次均保存结构化日志和短视频；每个物体另保存一段高质量代表视频。

## 11. 失败处理与断点续跑

- 每个阶段原子写入状态文件；只有证据合同验证通过的 PASS 才能断点跳过；
- 同一根因连续出现 3 次时，不停止整个测试；
- 自动进入全面排查：视频、标注、资产、识别、适配器、IK、控制接口、接触、成功谓词、渲染和证据写入；
- 修复公共根因后回归所有受影响物体；
- 单物体验收失败后重新执行该物体完整 10 种子集合；
- 所有历史失败、修复版本和重跑结果保留，不覆盖失败证据。

## 12. 自动化测试与防伪门禁

自动化测试至少验证：

- 固定 8 类和 60 个选择 ID 未改变；
- 每项操作规范可回溯到原始 JSON 和真实视频标注；
- 60 个适配器文件内容和 SHA256 不相同或具有可解释的独立训练来源；
- 验收识别请求不包含期望物体名称、选择 ID 或答案标签；
- 完整机械臂关节和夹爪在视频与轨迹中实际运动；
- 物体、工具或设备关节由物理接触变化，不由直接状态写入；
- 操作专用谓词与真实标注一致；
- 多物体和复合操作没有遗漏阶段；
- 600 个种子唯一且属于固定验收集；
- 每个物体恰好 10/10，整体恰好 600/600；
- 所有视频可解码，首帧、接触帧和末帧有效且不同；
- 缺少任一训练、模型、识别、轨迹或视频证据时不能输出 PASS。

## 13. 声明边界

本设计完成后可以声明：

- 8 类任务均由人体示范视频生成任务级技能表示，并由完整仿真机械臂复现；
- 60 种物体均逐一完成独立操作学习；
- 600 次无目标答案注入的视觉识别全部正确；
- 600 次完整机械臂仿真物理操作全部满足真实视频标注对应谓词。

不得声明：

- 已在真实机械臂上验证；
- 未执行的真实环境泛化能力；
- 纯 OpenVLA 逐动作控制，除非另有不含 IK 高层目标与安全控制的专项证据。
