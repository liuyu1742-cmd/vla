# VLA82 十项严格 PASS 资产外观批量增强设计

## 目标

增强以下严格 PASS 项目的物体辨识度，并重新生成高清结果视频：VLA82-004、005、014、017、019、036、038、042、045、060。外观优先匹配真实视频中可辨识的颜色和结构；原视频信息不足时采用常见、易识别的家用品配色。

## 技术路线

采用“多基础几何体视觉模型＋原碰撞体不变”的方式。所有新增外形部件使用非碰撞视觉几何；抓取、摩擦、质量、关节、控制器、目标区域和严格判定阈值保持不变。这样可以在增强外观的同时最大限度复用已验证轨迹。

不采用以下方案：

1. 视觉与碰撞同步重建：会改变夹持接触及柜门、抽屉边缘的可达性，需要十项重新调参。
2. 外部高模网格：会增加下载、授权、材质和加载依赖，不利于当前批量复现效率。

## 十项视觉规格

- **VLA82-004 清洁喷雾瓶**：半透明浅蓝瓶身、白色瓶颈、扳机喷头、喷嘴和清洁标签色块。
- **VLA82-005 打蛋器**：深色握柄、金属连接颈和多根闭合线圈构成的银色搅拌头。
- **VLA82-014 量杯**：半透明杯身、圆形杯口、侧把手、红色刻度线与容量标记色带。
- **VLA82-017 水瓶**：透明蓝色圆柱瓶身、瓶肩、蓝色瓶盖和环形防滑纹。
- **VLA82-019 罐装食物**：金属罐身、上下卷边、纸质标签带和顶部拉环。
- **VLA82-036 咖啡杯**：陶瓷圆柱杯身、开放杯口、可见内壁和 C 形把手。
- **VLA82-038 披萨刀**：圆形金属刀轮、轮轴、连接叉和深色握柄。
- **VLA82-042 洗碗刷**：保留现有把手与刷头，增加握持纹理、刷头圆角感、分组刷毛和双色刷毛层次。
- **VLA82-045 锡箔纸**：纸盒外壳、银色铝箔卷筒、外露箔片和锯齿切割边。
- **VLA82-060 皂液器**：半透明瓶身、瓶肩、泵头、按压嘴和液体颜色层。

## 生成与验证流程

1. 为十项视觉部件及原碰撞体数量编写自动化合同测试。
2. 修改统一资产生成器并重新物化十个 MJCF 文件。
3. 逐项加载 MuJoCo/RoboCasa 场景，检查模型、碰撞几何和摄像机。
4. 优先复用原严格 PASS seed；每项重新运行完整仿真并生成新的 JSON、NPZ。
5. 仅接受 `status=PASS`、`predicate_success=true`、错误为空且对应物理操作稳定完成的结果。
6. 每项生成 1280×720、30 FPS、正向无遮挡视频，并检查操作开始、中段和最终状态。
7. 更新严格 PASS 汇总表中的十项视频、JSON、NPZ绝对路径。

## 旧视频删除策略

- 每项新视频通过严格判定、参数检查和画面检查后，才删除该项汇总表当前指向的旧视频。
- 删除前解析并核对完整绝对路径，只处理这十个 VLA82 编号对应的 `.mp4` 文件。
- 新视频、严格判定 JSON、动作轨迹 NPZ 和汇总表不删除。
- 若某项新模型无法维持严格 PASS，则保留该项旧视频并在最终结果中说明，不进行破坏性替换。

## 完成标准

十项新视频均能清晰辨认目标物体及关键结构；全部保持严格 PASS；汇总表路径指向新证据；已经成功替换的旧视频被删除且删除清单可核对。
