# VLA82-048 笔记本叠放严格 PASS 设计

## 目标与语义

VLA82-048 的权威物体为“笔记本”，权威操作为“叠放于文件夹上”。运行时必须出现独立的笔记本和文件夹，目标关系为 `on`，不得继续使用历史的“台面到橱柜”映射。

## 场景与外观

使用 PandaOmron 与开放书桌支撑场景。笔记本从机器人可达的桌面区域开始，文件夹固定在另一块可达桌面区域。笔记本采用封皮、纸页、标签、装订脊和弹性带等可辨识几何；文件夹采用封皮、纸页、书脊和标签。碰撞体保持少量规则盒体，避免视觉细节破坏夹持稳定性。

## 操作闭环

将单一 `stack` 标注映射为完整的抓取—抬升—搬运—下降—受控释放闭环，但完成阶段仍记录为 `stack`。夹爪抓取笔记本凸起装订脊，避免手指与桌面竞争空间。目标为实体文件夹的碰撞表面，笔记本最终必须与该表面接触、释放后稳定且发生明显位移。

## 验证与归档

先用单元测试验证语义、场景对象、目标关系、外观几何和控制器路由，再运行 MuJoCo 闭环。严格 PASS 后生成1280×720正向无遮挡视频，检查一次抓取、连续搬运、目标接触、受控释放和末帧稳定，并将视频与完整判定 JSON 保存到 `C:\OpenVLA-Simulator\datasets\VLA82 video`。
