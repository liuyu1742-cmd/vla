# VLA82 材质摩擦与简单物体严格仿真设计

## 目标

在不修改物体位姿、关节状态、成功判据和接触事件的前提下，为 VLA82 物体建立可追溯的材质摩擦配置，并优先完成尚未严格通过的简单单物体操作。每个新增 PASS 必须来自机器人在 MuJoCo 中的真实接触、抓取、移动和释放。

## 当前问题

自定义资产除海绵外统一使用 `friction="0.95 0.3 0.1"`，没有表达陶瓷、玻璃、金属、塑料、纸板和木材之间的差异。统一提高摩擦会使光滑杯具不真实，也可能掩盖夹爪轨迹或接触规划缺陷。

## 设计选择

采用“材质基准 + 物体类别微调”的确定性配置。配置只写入对象碰撞几何的 MuJoCo `geom_friction`，三元组依次为滑动、扭转和滚动摩擦；视觉几何、夹爪、支撑面和成功判据保持不变。

不采用以下方案：

- 全局提高所有物体摩擦：最快，但缺乏物理区分并可能制造虚假稳定抓取。
- 每次实验临时手调：可以处理单例，但不可复现且难以审计。

## 摩擦基准

| 材质类别 | 滑动摩擦范围 | 首选值 | 扭转摩擦 | 滚动摩擦 | 典型对象 |
|---|---:|---:|---:|---:|---|
| 光滑陶瓷/玻璃 | 0.35–0.45 | 0.40 | 0.004 | 0.0001 | 马克杯、咖啡杯、量杯 |
| 金属 | 0.40–0.50 | 0.45 | 0.004 | 0.0001 | 打蛋器、夹子、汤勺 |
| 普通塑料 | 0.50–0.60 | 0.55 | 0.005 | 0.0002 | 保鲜盒、饮料盒、喷雾瓶 |
| 纸质/纸板 | 0.60–0.70 | 0.65 | 0.006 | 0.0002 | 纸箱、铝箔纸外包装 |
| 木质 | 0.75–0.90 | 0.82 | 0.008 | 0.0003 | 木勺、木块、擀面杖 |
| 橡胶/海绵 | 0.90–1.10 | 1.00 | 0.012 | 0.0005 | 海绵、软质清洁工具 |

范围用于边界检查，首选值用于本轮确定性实验。对象语义与材质不明确时使用普通塑料基准并在证据中记录 `material_source="semantic_fallback"`，不得为了通过测试临时提高系数。

## 软件边界

新增独立摩擦配置模块，负责：

1. 将 VLA82 对象名称映射为材质类别；
2. 返回不可变的摩擦三元组与来源；
3. 定位当前被测对象的碰撞几何；
4. 在环境构建后、第一次控制步之前应用参数；
5. 生成包含 geom 名称、修改前后参数和配置版本的证据记录。

现有资产生成逻辑调用该配置，避免继续把所有自定义物体写成同一摩擦值。对于 RoboCasa 原生资产，在模型加载后通过 `model.geom_friction` 应用同一配置。参数写入是模型动力学配置，不是运行时状态注入。

## 第一批实验

按“单物体、短路径、无复杂柜门联动、已有清晰语义标签”排序：

1. `VLA82-006` 擀面杖，木质，台面到抽屉；
2. `VLA82-014` 量杯，光滑杯具，台面到抽屉；
3. `VLA82-018` 盒装饮料，纸板，橱柜到台面；
4. `VLA82-037` 夹子，金属，橱柜到台面；
5. `VLA82-041` 汤勺，金属，台面到橱柜；
6. `VLA82-045` 铝箔纸，纸质包装，台面到橱柜。

每个对象先运行一个固定种子诊断回合。若失败，按照接触链依次检查可达性、夹爪接触、稳定抬升、运输碰撞、目标区域和释放后稳定性；不得通过放宽谓词获得 PASS。

## 严格成功条件

一次严格 PASS 同时要求：

- 存在夹爪与指定对象碰撞几何的真实接触；
- 对象相对初始状态发生满足任务要求的物理状态变化；
- 抓取类任务包含离开支撑面的稳定抬升；
- 对象通过机器人控制到达真实目标区域并释放；
- 释放后持续稳定窗口内仍满足最终谓词；
- 诊断中不存在直接 `qpos`、`qvel` 或对象位姿写入；
- 视频能同时看见机器人、对象和目标区域。

## 证据输出

每回合 JSON 增加 `friction_evidence`：配置版本、材质类别、映射来源、目标 geom、原始摩擦三元组、应用后摩擦三元组及应用时刻。NPZ 保留动作、观测和谓词轨迹；PASS 回合生成无遮挡视频和首帧/接触帧/末帧图片。失败回合保留诊断，但不标记为 PASS。

## 验证策略

- 单元测试覆盖名称到材质的映射、数值边界、未知材质回退和仅修改碰撞 geom。
- 集成测试验证模型加载后的实际 `geom_friction` 与证据 JSON 一致。
- 回归测试保证现有 12 个严格 PASS 的成功谓词不因摩擦配置接口变化而被放宽。
- 第一批逐项运行，只有严格谓词成功且证据文件完整才更新台账。
