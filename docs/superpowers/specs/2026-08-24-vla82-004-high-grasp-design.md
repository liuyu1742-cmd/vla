# VLA82-004 高位夹持放置设计

## 目标

在不修改物理状态、不伪造判定的前提下，使 VLA82-004 的清洁喷雾瓶能从柜内取出，并以竖直姿态受控接触台面、释放和稳定。

## 已验证的根因

当前控制器在瓶身中部侧夹后用腕部旋转把瓶身转竖直。该旋转令末端参考点落在瓶身中心略下方；台面接触需要将该参考点继续下降至机械臂可达范围之外。不同的底盘微调只能改善少量高度，不能改变夹持点与瓶身的相对关系。

## 选定方案

采用瓶颈/喷头下方的高位侧夹持：

1. 依据喷雾瓶碰撞几何的长轴，计算瓶身上部的可夹持点；该点位于瓶身中心沿长轴正方向的固定偏移处，并保留喷头和顶部边缘的安全距离。
2. 在柜内接近阶段将夹爪横向对准这个高位点，保持原有的碰撞检测和双指接触判定。
3. 获得真实抓取后，仅在安全抬升高度进行姿态预对齐；运输和下降阶段维持瓶身长轴竖直。
4. 下降时根据实时瓶身旋转计算台面接触高度；只有目标接触、近期夹持释放、稳定帧和最终竖直同时满足时才记录 PASS。

## 不做的事情

- 不直接写入 MuJoCo 物体位置、姿态或接触状态。
- 不改变 VLA82-004 的目标台面，也不以悬空释放替代台面接触。
- 不将失败轨迹写回严格 PASS 台账。

## 验证标准

- 高位目标点位于喷雾瓶的有效长轴区间内，且相对中心至少上移 35 mm。
- 全流程使用公共动作接口；原有抓取和碰撞门槛仍有效。
- `spray_bottle_upright_cosine >= cos(12°)`，存在台面接触、受控释放和稳定帧。
- 仅在上述条件均满足时生成新视频和更新严格 PASS 表格。
