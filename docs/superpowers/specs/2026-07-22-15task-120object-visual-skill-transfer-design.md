# 15类任务与120物体视觉技能迁移项目总设计

## 1. 主要验收目标

项目以以下能力为主标准：

> 基于视觉的人类动作捕获、解析和技能学习迁移技术，使家政服务机器人支持不少于15类典型任务和120类典型物体的操作技能学习。

验收关注系统是否能从人类示范视频中获取任务、对象、动作阶段和目标状态，并在机器人自身视觉反馈下完成等价操作。项目不以“是否使用单一端到端大模型”作为验收条件，也不把固定轨迹回放、只识别物体或只输出语言描述计为技能迁移成功。

## 2. 技术路线原则

采用结果导向的混合架构：

- 视觉算法负责人体/手部关键点、对象检测/分割/跟踪、手—物接触和对象状态变化。
- 时序模型和大模型负责动作分段、任务语义、对象关系与技能图生成。
- `Skill IR` 作为人类视频、机器人执行和不同任务后端之间的统一表示。
- 重定向、逆运动学、专家控制器和规划器负责产生可执行机器人示教及训练标签，不固化为唯一运行轨迹。
- OpenVLA或其他VLA策略根据机器人当前视觉、当前技能阶段和状态输出连续动作。
- DAgger和失败恢复数据用于提高闭环鲁棒性。
- 安全监督器负责动作边界、接触顺序、碰撞、抓取保持、失败重试和紧急停止。
- 严格的“示范视频直接条件化VLA”作为后期降低模块依赖和提高泛化的优化方向，不作为前期覆盖15/120的阻塞项。

## 3. 什么算支持一类任务

一类任务只有同时满足以下条件才计入15类覆盖：

1. 至少存在一段真实或公开的人类示范视频。
2. 系统自动生成通过校验的 `Skill IR`，不得手工填写完整阶段序列后冒充解析结果。
3. 任务具有明确执行后端、输入状态、动作空间、成功条件和失败原因。
4. 机器人/模拟机器人在当前视觉反馈下闭环执行，而不是只播放与场景无关的固定电机序列。
5. 至少3种适用对象在5个独立场景种子上评测，每类任务成功率不低于80%。
6. 结果报告能追溯源视频、解析结果、Skill IR、动作轨迹、监督器干预和最终成功谓词。

## 4. 什么算支持一个物体

一个物体只有同时满足以下条件才计入120物体覆盖：

1. 在对象注册表中具有唯一ID、名称、类别、对象族和视觉类别。
2. 声明可执行技能、抓取/操作属性、有效目标和执行后端。
3. 在至少一个适用任务中被视觉系统识别或跟踪。
4. 至少完成3次独立操作试验，其中不少于2次达到任务成功条件。
5. 报告保存对象可见性、识别置信度、操作技能、轨迹和结果。

120物体表示120个唯一可操作实体或类别，不要求执行全部 `15 × 120` 组合。系统维护任务—物体适用性矩阵，只对物理和语义上合理的组合验收。

## 5. 15类任务定义

项目将需求示例整理为以下15类可实施任务：

1. 物体抓取与放置。
2. 物体分类与整理。
3. 柜体、抽屉和储物空间整理。
4. 容器、柜门和抽屉开合。
5. 物品装载与卸载。
6. 液体或颗粒倾倒与转移。
7. 桌面和台面擦拭。
8. 地毯清洁。
9. 木地板和瓷砖硬地面清洁。
10. 衣物洗涤装载与取出。
11. 衣物折叠与分类。
12. 鞋、帽和柔性日用品整理。
13. 家电按钮、旋钮、遥控器和触控操作。
14. 智能家电任务执行与综合管理。
15. 智慧安防、环境和健康设备查看与控制。

任务注册表允许后续调整展示名称，但任务ID、成功条件和覆盖统计必须保持稳定并有版本记录。

## 6. 对象族与120物体扩展

120物体不逐一建立独立策略，而按操作属性共享技能：

1. 杯、瓶、罐等刚性容器。
2. 碗、盘和托盘。
3. 刀、叉、勺和厨房工具。
4. 带把手物体。
5. 盒、袋和包装。
6. 书籍、遥控器和小型刚性日用品。
7. 毛巾、抹布和清洁工具。
8. 儿童服装、棉衣、羽绒和羊毛制品。
9. 鞋、帽和其他柔性日用品。
10. 柜门、抽屉、窗帘和门锁等可动家具部件。
11. 灯具、电视、空调、冰箱、洗衣机、电饭煲等家电。
12. 空气净化器、晾衣架、扫地机器人、摄像头、温湿度/体重设备等智能设备。

对象注册表包含：

  "valid_targets": ["cabinet", "sink", "counter"],
  "execution_backend": "robocasa_manipulation"

## 7. 系统架构

### 7.1 人类示范通路

`视频输入 → 人/手关键点 → 对象跟踪 → 手—物交互 → 动作阶段 → Skill IR`

输出任务动词、对象、目标、阶段序列、接触事件、对象相对运动、前置条件、成功条件和置信度。

### 7.2 机器人学习与执行通路

`Skill IR → 后端选择 → 状态提供器 → VLA/技能策略 → 安全监督 → 执行 → 反馈/恢复`

执行策略可以是OpenVLA、阶段条件化策略、任务空间策略、设备控制策略或其组合，但所有策略必须遵循统一状态、动作和报告接口。

### 7.3 数据闭环

`人类视频 → Skill IR → 专家/重定向机器人示教 → VLA训练 → 闭环评测 → DAgger恢复 → 再训练`

传统方法用于生成动作教师和约束，现代模型用于理解、决策和泛化；两者的输出在报告中明确区分。

## 8. 执行后端

由于15类任务跨越刚性操作、清洁、柔性物体和设备管理，项目采用多个后端共享同一Skill IR：

### 8.1 刚性操作后端

- RoboCasa/PandaOmron。
- 覆盖抓取放置、整理、柜体开合、装卸和倾倒。
- OpenVLA输出7D末端动作，状态监督器提供安全恢复。

### 8.2 表面清洁后端

- 表面区域、覆盖率和接触状态驱动的轨迹控制。
- 覆盖桌面擦拭、地毯、木地板和瓷砖清洁。
- 评测区域覆盖率、残留率、碰撞和完成时间。

### 8.3 柔性物体后端

- 衣物/柔性物体仿真或可验证关键点状态机。
- 覆盖洗衣装卸、折叠、分类和鞋帽整理。
- 评测目标关键点误差、折叠状态、放置区域和完成率。

### 8.4 设备与家庭服务后端

- 视觉按钮/旋钮操作、遥控器操作、设备API或数字孪生接口。
- 覆盖灯具、电视、空调、窗帘、空气净化器、电饭煲、扫地机器人、门锁、摄像头和环境/健康设备。
- 评测设备状态是否达到目标，而不是只验证发出命令。

## 9. 状态、动作与安全契约

统一机器人状态至少包含：

- 当前视觉观测。
- 对象可见性、类别、位姿/区域和置信度。
- 机器人末端、夹爪或移动底盘状态。
- 当前Skill IR阶段。
- 最近动作与完成谓词。

统一动作记录至少包含：

- 学习策略原始动作。
- 最终执行动作。
- 动作来源和监督器干预原因。
- 动作合法性和控制频率。

模拟器真值只允许用于专家数据、诊断和早期后端验收。每个正式视觉闭环必须声明状态来源，禁止把模拟器真值结果报告为纯视觉系统结果。

## 10. 评测矩阵

系统维护以下四张清单：

1. `task_registry.json`：15类任务、阶段模板、后端和成功条件。
2. `object_registry.json`：120物体、对象族、视觉类别和操作属性。
3. `task_object_matrix.json`：合理的任务—物体组合及禁用原因。
4. `evaluation_manifest.json`：视频、场景、种子、模型和报告路径。

核心指标：

- 视频解析阶段F1或边界误差。
- 对象识别/跟踪成功率。
- Skill IR校验通过率。
- 每类任务成功率。
- 每个物体操作成功次数。
- 学习策略直接执行率。
- 安全监督器干预率。
- 平均完成步数、失败类型和恢复率。

## 11. 分阶段交付

### 阶段A：标准与注册表

- 固化15任务ID、120物体ID、对象族、适用矩阵和验收规则。
- 将现有水杯轨迹导入通用VLA episode manifest。

### 阶段B：首条人类视频技能迁移

- 完成 `人拿杯子放柜 → Skill IR → RoboCasa/OpenVLA成功`。
- 以 `seed 0` 和 held-out `seed 2` 为机器人端验收。

### 阶段C：通用刚性抓取放置

- 扩展杯、碗、瓶/调料瓶到柜子、水槽和台面。
- 建立阶段条件化训练、批量专家/DAgger采集和多种子评测。

### 阶段D：原子技能库

- 完成 `locate、reach、grasp、release、transport、place、open、close、push、pull、press、pour、wipe、fold、navigate`。
- 每个原子技能具有输入、完成谓词、恢复策略和后端适配器。

### 阶段E：四类后端覆盖

- 刚性操作、表面清洁、柔性物体、设备/家庭服务分别形成至少一个端到端样板。
- 用共享Skill IR组合为15类任务。

### 阶段F：120物体规模化

- 按对象族批量采集视觉和机器人数据。
- 逐对象完成注册、视觉验证和至少一个操作技能验收。

### 阶段G：总体验收

- 15类任务全部满足任务支持标准。
- 120物体全部满足物体支持标准。
- 输出覆盖矩阵、失败分布、监督器依赖和可复现实验报告。

## 12. 当前下一步

当前后半段机器人执行链已具备水杯受监督成功证据，因此下一步先完成阶段A和阶段B：

1. 建立任务、对象和任务—对象注册表的数据契约。
2. 将一个现有人类水杯视频自动解析成Skill IR。
3. 用该Skill IR驱动现有水杯OpenVLA闭环。
4. 生成从源视频到seed 0/2机器人报告的端到端证据。

这条闭环完成后，再扩展多物体抓取放置；不先为单个水杯增加训练轮数，也不以严格的视频直接VLA阻塞15/120覆盖。
