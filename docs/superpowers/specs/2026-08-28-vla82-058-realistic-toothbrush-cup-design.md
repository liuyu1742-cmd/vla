# VLA82-058 牙刷与漱口杯视觉增强设计

## 目标

在不改变 VLA82-058 已验证操作语义、碰撞包络和控制轨迹的前提下，提高牙刷与漱口杯在 720p 审核视频中的外观辨识度。最终画面应能直接辨认出蓝白牙刷、刷头、刷毛、圆柱杯口和杯内腔。

## 方案比较

1. **视觉几何增强、碰撞体保持不变（采用）**：使用多个 MuJoCo 基础几何体组成外观，复用现有碰撞体。改动小、渲染快，最不容易破坏严格 PASS。
2. **视觉与碰撞几何同步重建**：物理轮廓更精确，但会改变抓取接触、杯沿碰撞和插入轨迹，需要重新调参，风险较高。
3. **导入外部高精度网格模型**：外观最细致，但增加模型、材质和授权依赖，也可能降低仿真与视频生成效率。

## 视觉设计

### 牙刷

- 保留现有细长盒状碰撞体及整体尺寸。
- 用圆角感更强的细柄、收窄颈部和椭圆刷头组成蓝白刷体。
- 在刷头一侧排列多簇短白色刷毛，并使用少量浅蓝刷毛形成可辨识色带。
- 所有新增细节均为非碰撞视觉几何，不参与抓取判定。

### 漱口杯

- 保留现有五壁开口容器碰撞几何、内腔目标区域和摆放位置。
- 将方盒外观替换为浅蓝色圆柱杯壁，用多个无碰撞圆柱/环形视觉部件表现杯身、杯口厚度和底部。
- 杯口保持真正开放，不使用封闭顶面；内部使用较深颜色帮助观察牙刷是否进入杯中。
- 不增加把手，避免视觉遮挡，并保持常见简洁漱口杯形态。

## 数据与运行边界

- 修改资产生成逻辑，使重新物化资产后仍保持增强外观，避免只手改生成产物而被后续覆盖。
- 资产的碰撞几何名称、数量、尺寸、摩擦参数及 `reg_bbox` 保持兼容。
- 不修改专家控制器、目标判定阈值和已保存的严格 PASS 口径。

## 验证

1. 先以自动化测试断言 VLA82-058 生成的 XML 包含牙刷柄、刷头、刷毛、圆柱杯身和杯口视觉部件，同时碰撞几何合同保持不变。
2. 重新物化两个资产并运行 MuJoCo 场景加载检查。
3. 使用 seed 2005 重新执行完整仿真，要求 `PASS`、`predicate_success=true`、杯内容纳、目标接触、受控释放和稳定停留全部成立。
4. 重新生成 1280×720、30 FPS 正向无遮挡视频，检查开始、抓取、越杯沿、插入和最终稳定画面。
5. 更新严格 PASS 汇总表中 VLA82-058 的结果视频路径；仅在全部验证通过后替换现有视频。
