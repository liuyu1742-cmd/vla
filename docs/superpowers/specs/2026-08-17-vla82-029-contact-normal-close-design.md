# VLA82-029 接触法向保持式关门设计

## 1. 目标与证据

本设计承接 VLA82-029 微波炉门自由边绕行控制。机器人已经能够完成门板自由边绕行并进入正确关门侧，但第三轮物理轨迹仍表现为 87 个单帧接触段：每次接触后沿纯铰链切向移动，下一帧立即失去接触；随后重新贴合并再次脱离。门铰链角一度从约 `-1.57 rad` 改善到 `-1.47 rad`，但最终回弹至开启端。

轨迹中的真实接触法向主要指向世界坐标正 X、正 Y，而当前关门切向主要指向负 Y，两者点积为负。纯切向指令因此包含离开接触面的分量。目标是在不改变铰链闭合目标、不写入关节状态的前提下，将关门切向与小幅实时法向压紧分量合成，使机器人持续接触并产生稳定关门力矩。

## 2. 方案选择

采用实时接触法向合成方案。它直接利用 MuJoCo 已产生的机器人—微波炉门接触，不猜测固定世界方向，也不需要重新选择一块尚未验证可达的门板区域。

未采用的替代方案：

- 重新绕行到门板中央平面：可能获得更理想的接触法向，但需要重新设计路径和可达性，成本更高。
- 改用完整力/阻抗控制器：控制效果可能更平滑，但会引入新的控制栈和更多参数，不适合当前单物体快速闭环。
- 单纯增大推力：不能消除运动方向离开接触面的几何原因。

## 3. 接触法向来源

仅使用当前微波炉门关节所绑定几何体与 Panda 夹爪、掌部碰撞体之间的真实 MuJoCo 接触。其他家具、工作台、机器人自碰撞和非目标物体接触不得参与方向计算。

每个控制周期从有效接触中选择穿透深度最大的接触项，其 `normal_gripper_to_object` 定义为从机器人接触体指向目标门体的单位向量。若接触法向长度退化或接触对象不属于所选门关节，则本周期不生成法向压紧指令。

为降低相邻碰撞几何体之间的法向跳变，保存上一帧有效法向，并执行指数平滑：

`n_filtered = normalize(0.65 × n_previous + 0.35 × n_current)`

若新法向与上一法向点积为负，先将新法向取反再平滑，避免碰撞对顺序变化造成方向翻转。首次有效接触直接使用当前法向。

## 4. 关门方向合成

设：

- `t` 为现有 `fixture_close_push_direction` 计算的单位关门切向；
- `n` 为平滑后的、从机器人指向门体的单位接触法向；
- `m = 0.08` 为期望的最小向内方向余量；
- `a_max = 0.45` 为法向补偿上限。

先计算纯切向相对接触面的向内分量 `d = dot(t, n)`，再计算：

`a = clip(m - d, 0, a_max)`

最终单位运动方向为：

`u = normalize(t + a × n)`

当纯切向已经具有足够向内分量时，`a = 0`，不会添加多余压紧力；当纯切向包含离面分量时，只补足维持接触所需的法向分量，并通过 `a_max` 保留主要关门切向。每步平移距离继续使用现有铰链短步长 `0.01 m`，不增加控制速度上限。

## 5. 接触丢失后的重新贴合

完成自由边跨面且曾经与门体接触后，不再返回绕行路径点，也不再以远处语义把手中心作为重新接触目标。

若当前帧失去真实接触：

1. 保持上一帧有效平滑法向；
2. 从当前夹爪接触参考点沿该法向向门体移动 `0.006 m`；
3. 状态保持为 `seat_contact`，不施加关门切向；
4. 重新出现目标门体真实接触后，立即恢复合成方向推门。

若连续 20 帧仍未重新接触，停止使用陈旧法向，回到当前门板几何体的短距离接触目标，但不得退回门板错误侧。该回退过程继续保持固定底盘。

## 6. 组件边界

新增两个纯函数：

- `fixture_close_filtered_contact_normal(previous, current)`：处理方向一致性、指数平滑和单位化。
- `fixture_close_contact_preserving_direction(tangent, contact_normal, minimum_inward=0.08, max_normal_bias=0.45)`：计算受限的接触保持式关门方向。

`DrawerClosePrimitive` 只负责读取目标门体接触、保存上一帧法向、选择 `push_close` 或 `seat_contact` 目标，并记录诊断字段。纯函数不读取仿真环境，便于独立测试。该逻辑仅在 `fixture_close_requires_free_edge_bypass(joint_id)` 为真且已经完成跨面后启用；其他抽屉、冰箱门、烤箱门和柜门行为保持不变。

## 7. 诊断记录

每个相关轨迹帧增加：

- 原始目标接触法向；
- 平滑接触法向；
- 原始关门切向；
- 法向补偿系数 `a`；
- 最终合成方向；
- 本轮接触连续帧数；
- 接触丢失后的重新贴合帧数；
- 实际接触的机器人几何体和门体几何体。

这些字段用于判断失败来自法向方向、补偿限幅、目标几何切换、机械臂可达性还是门体回弹，不以视频外观代替物理诊断。

## 8. 测试与验证

先执行测试驱动开发：

1. 纯切向与法向点积为负时，合成方向必须具有至少接近 `0.08` 的向内分量，同时保持与原关门切向为正相关。
2. 纯切向已经向内时不得增加法向补偿。
3. 法向补偿不得超过 `0.45`。
4. 新旧法向反向时必须先校正方向再平滑。
5. 退化法向必须明确报错或返回无补偿结果，不得产生 NaN。
6. 非微波炉关闭任务不得使用该合成方向。
7. 接触丢失后目标必须是当前接触参考点加上一帧法向的 `0.006 m` 小步，而不是远处把手中心。

单元测试和现有回归全部通过后，运行一轮新的 VLA82-029 MuJoCo 物理仿真。若失败，仅依据新的接触连续性、合成方向和关节角轨迹判断下一原因。

## 9. 严格 PASS 条件

VLA82-029 只有同时满足下列条件才可更新为严格 PASS：

- 自由边绕行和正确侧跨面过程无穿模、瞬移或直接状态写入；
- 目标门体与机器人产生连续多帧真实物理接触，不再以单帧交替为主；
- 合成方向在维持接触的同时保留正确关门切向；
- 铰链角从开启位置持续向 `0 rad` 变化并进入现有严格关闭阈值；
- 门体在结束阶段稳定保持关闭，无明显回弹；
- 轨迹 JSON、谓词、接触记录和无遮挡高清视频内容一致。

未满足全部条件时继续标记 FAIL，不生成严格 PASS 视频，也不更新汇总表。

## 10. 停止条件

若法向合成后接触连续性明显改善但关节角不再改善，则下一步调查接触点力臂和机器人工作空间；若接触仍以单帧交替且合成方向日志正确，则说明当前位置或碰撞几何不适合作为持续推门接触点，应停止微调系数并重新评估门板中央接触路径。只有新的物理证据能够区分原因时才继续修复。
