# VLA82-029 微波炉门物理闭合控制设计

## 1. 目标

修正 VLA82-029 微波炉门关闭控制中的铰链切向符号，使机械臂在与门体真实接触后，将门关节从打开端 `-1.5708 rad` 连续推向关闭端 `0 rad`，最终满足严格闭合谓词并保存无遮挡结果视频。

## 2. 已确认根因

当前控制器已经完成末端工具姿态对齐、把手方向对齐和门体接触。最新基线共执行 700 步，其中 `push_close` 201 步，全部具有真实门体接触。

微波炉门关节范围为 `[-1.570796, 0]`，关闭目标是 0。实际推门阶段关节从约 `-1.5796` 回弹到 `-1.5714` 后停在完全打开端的机械限位，没有向零位持续运动。

对于铰链轴 `axis`、铰链到接触点的杠杆 `lever`，增大关节坐标的物理点速度方向是 `cross(axis, lever)`。当关节值为负时，关闭需要增大关节值，因此应沿该方向施力。现有实现额外取反，导致命令朝继续开门的方向施力。

## 3. 控制设计

铰链关闭方向统一按以下规则计算：

- `sign_to_zero = -1`：关节为正，需要减小到零；
- `sign_to_zero = +1`：关节为负，需要增大到零；
- 铰链目标切向：`sign_to_zero * cross(axis, lever)`；
- 滑动关节继续使用 `sign_to_zero * axis`，不受本次修改影响。

控制器只有检测到夹爪与目标门体真实接触后，才能进入 `push_close`。接触丢失时返回把手进近，不允许隔空推进状态。推门阶段使用正常动作向量驱动末端，不直接写入门关节位置或速度。

## 4. 成功与停止判据

严格 PASS 必须同时满足：

- 机械臂与所选微波炉门体存在真实物理接触；
- 门关节从打开端持续朝 0 方向运动；
- 最终关节绝对值进入现有关闭阈值；
- 控制轨迹包含关闭完成事件；
- `status=PASS`、`predicate_success=true` 且 `errors=[]`；
- 保存 JSON、NPZ 和清晰无遮挡结果视频。

取消固定 5 次限制。每轮只根据首个失败物理门槛修改一个变量。只要轨迹产生新的、可验证的根因证据，就继续修复；当连续重跑仅重复同一失败状态、没有新的可控变量，或修复必须依赖直接状态写入/放宽谓词时，判定继续修复无意义并停止。

## 5. 测试策略

1. 先增加运动学单元测试：负关节角、Z 轴铰链、X 向杠杆必须产生正 Y 切向；正关节角必须产生相反切向。
2. 运行测试并确认现有实现按预期失败。
3. 只修改铰链切向符号，验证测试转绿。
4. 运行全部 VLA82 源场景、闭环和谓词回归测试。
5. 运行 VLA82-029 完整 MuJoCo 仿真，检查接触阶段的关节值是否逐步趋近 0。
6. 若失败，记录首个门槛并按一次一个变量继续诊断。
7. 严格 PASS 后生成 1280×720 或更高清晰度视频，检查起始开门、接触、完整闭合和最终稳定画面，再更新严格 PASS 汇总表。

## 6. 回归保护

本次符号修复会影响所有铰链型关闭任务，因此必须回归检查柜门、冰箱门、烤箱门和洗碗机门的方向计算。滑动抽屉及烤盘控制保持原有公式。已有严格 PASS 物体的轨迹和视频不得被覆盖。
