# VLA82-029 抬升阶段受限底盘辅助设计

## 1. 目标与物理证据

上方宽门板路径已正确选择 `microwave_main_group_1_g12`，并生成抬升目标 `[-1.4075, -4.3421, 1.3970] m`。机器人完成自由边跨面后，在 `raise_above_handle` 阶段运行 371 步，无任何碰撞，但夹爪接触参考点最终稳定在约 `[-1.4231, -4.3439, 1.3741] m`，与目标仍相差 `27.8 mm`。现有阶段阈值为 `25 mm`，且实际高度仅比把手中心高约 `54 mm`，不足设计要求的 `70 mm`，因此不能通过放宽阈值或降低目标高度解决。

本设计仅在抬升阶段确认机械臂进入工作空间平台期后，允许移动底盘不超过 `0.05 m`，改善机械臂姿态并达到原安全高度。抬升完成后立即锁定底盘，后续横移、贴合和推门继续使用固定底盘。

## 2. 辅助触发条件

进入 `raise_above_handle` 时记录抬升目标、初始底盘位姿和每帧夹爪到目标的距离。仅同时满足以下条件才启用底盘辅助：

- 当前阶段仍为 `raise_above_handle`；
- 已连续执行至少 60 帧；
- 当前距离仍大于 `0.025 m`；
- 最近 40 帧的距离改善小于 `0.003 m`，确认机械臂进入平台期；
- 当前无材料级移动底盘—固定家具碰撞；
- 累计底盘平移小于 `0.05 m`。

在前 60 帧内只使用机械臂抬升，避免不必要的底盘运动。若机械臂能够自行达到目标，则本轮完全不启用辅助。

## 3. 底盘移动方向与限幅

计算夹爪接触参考点到抬升目标的世界坐标误差，只使用其 XY 分量。通过实时底盘旋转矩阵转换到本地坐标，并归一化为移动方向。

底盘平移命令幅值固定为 `0.08`，低于现有接近控制的 `0.16`，减少厨房环境中的碰撞风险。每帧通过底盘实时世界位置计算相对辅助起点的累计平移，不依靠控制步数估算实际距离。

以下任一条件出现时立即停止底盘辅助并将 `base_mode` 恢复为固定模式：

- 抬升目标距离进入 `0.025 m`；
- 累计底盘平移达到 `0.05 m`；
- 检测到移动底盘与固定家具的材料级接触，接触距离小于或等于 `-0.001 m`；
- 当前阶段离开 `raise_above_handle`；
- 目标 XY 误差退化为零。

## 4. 碰撞保护

每帧扫描 MuJoCo 接触，使用现有 `is_material_mobile_base_fixture_contact` 规则识别移动底盘与固定家具的有效穿透，忽略求解器级擦碰噪声。发生材料级接触后：

1. 当帧不再发送底盘移动命令；
2. 锁定本轮底盘辅助，不自动反向或反复重试；
3. 保留机械臂抬升控制；
4. 在轨迹中记录碰撞几何体、穿透距离、已移动距离和剩余抬升误差。

若锁定后机械臂仍无法达到目标，本轮自然以 FAIL 结束，不通过修改结果或阈值绕过。

## 5. 状态与组件

新增纯函数：

- `fixture_raise_base_assist_local(...)`：根据阶段帧数、距离历史、目标误差、底盘旋转、累计位移和碰撞状态，返回二维本地底盘命令或 `None`。

`DrawerClosePrimitive` 只负责维护 40 帧距离窗口、记录辅助起点、读取实时底盘位姿、调用纯函数并写入正常 PandaOmron 动作向量。现有上方宽门板目标、接触集合和关门控制保持不变。

辅助只在 VLA82-029 微波炉门的 `raise_above_handle` 阶段启用。自由边绕行、跨面、横移、贴合、推门、其他微波炉操作以及所有非微波炉任务均不得使用该底盘辅助。

## 6. 轨迹记录

每帧增加：

- 抬升阶段累计帧数；
- 最近距离窗口的首值、末值和改善量；
- 抬升目标距离；
- 底盘辅助是否具备触发条件；
- 二维本地底盘命令；
- 辅助起点与当前底盘世界位置；
- 累计底盘平移距离；
- 是否达到 `0.05 m` 上限；
- 是否检测到材料级底盘—家具碰撞；
- 辅助是否被碰撞永久锁定。

## 7. 测试策略

通过 TDD 验证：

1. 少于 60 帧时不启用底盘。
2. 距离仍明显改善时不启用底盘。
3. 60 帧后、40 帧改善小于 `0.003 m` 且距离大于 `0.025 m` 时，返回幅值 `0.08` 的本地平移命令。
4. 世界目标误差必须依据底盘旋转正确转换到本地坐标。
5. 累计位移达到 `0.05 m`、发生材料级碰撞、离开抬升阶段或 XY 误差退化时均返回 `None`。
6. 非微波炉任务不得调用辅助。
7. 上方路径完成后底盘必须保持固定。

完整单元、闭环和谓词回归通过后，执行一轮新的 VLA82-029 物理仿真。主要检查底盘实际移动距离、抬升目标是否达到、后续上方横移是否开始、以及是否出现新的底盘碰撞。

## 8. 成功与停止条件

本方案阶段性成功要求：

- 底盘移动不超过 `0.05 m`；
- 无材料级底盘—固定家具碰撞；
- 夹爪达到原 `1.397 m` 安全抬升目标的 `0.025 m` 范围；
- 状态进入 `traverse_to_upper_panel`；
- 进入横移后底盘保持固定。

VLA82-029 的最终严格 PASS 条件仍不变：必须形成宽门板连续真实接触、铰链角持续趋近 `0 rad`、达到严格关闭阈值并稳定保持，且证据文件与无遮挡视频一致。

若底盘移动达到上限仍无法完成抬升，或出现材料级底盘碰撞，则停止该辅助方案，不继续增加位移上限；下一步改为重新选择固定底盘下可达的宽门板接触路径。
