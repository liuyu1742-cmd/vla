# VLA82 抽屉与困难物体严格 PASS 修复设计

## 目标与顺序

按 VLA82-045、005、042、004/017/020、007、038 的顺序推进。每项必须以真实物理闭环、无遮挡高清视频和轨迹证据通过；旧谓词单独返回 PASS 不构成合格。

## 抽屉放置轨迹

045 与 005 采用分段路点：抓取、抬升、抽屉上方预对齐、水平移动到开口中心、锁定底盘和腕部、单轴垂直下降、接触支撑面、主动释放、垂直撤离。进入开口后禁止底盘移动和腕部姿态修正。碰撞检查使用“物体与夹爪整体包围盒”，保证夹爪不碰抽屉前板和边沿。

005 的抓取点偏向打蛋器手柄端，使夹爪停留在抽屉口上方；045 使用固定路点并删除插入前重复退让。所有路段使用有下限的平滑速度，禁止长时间微动。

## 洗碗刷资产

042 替换为可辨识的同类仿真数字资产，至少包括手柄、刷头和刷毛区域。碰撞体保持简化但覆盖实际外形，重新验证抓取、柜内放置和视频可见性。

## 困难抓取与设备操作

004、017、020 共用离线抓取候选筛选：在少量候选高度、横向偏移和夹爪角度中，先用短时物理探针淘汰推碰、单指接触和抬升滑脱，再执行完整轨迹。007 将按钮和锅体动作拆成两个明确阶段，按钮完成后先撤离。038 使用抽屉三维安全通道并在插入阶段锁定底盘。

## 严格验收

- 抓取后连续保持，不得中途掉落或重新抓取。
- 进入抽屉开口后底盘保持静止，夹爪不得接触抽屉边沿或前板。
- 物体受控下降并主动释放，不以自由跌落完成操作。
- 释放后稳定停留，无遮挡视频完整呈现操作。
- 单项困难对象最多五次有明确假设的完整修复运行；到达上限即停止并记录原因。
