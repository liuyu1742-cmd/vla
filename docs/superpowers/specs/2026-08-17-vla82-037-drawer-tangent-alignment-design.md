# VLA82-037 抽屉切向对齐设计

## 2026-08-17 物理边界修订

对真实 Omron 与打开抽屉碰撞体进行 5 mm 步进扫描后确认：完全横向对齐时，
底座中心与目标物体的最小无碰撞距离约为 0.409 m；原定 0.39 m 同时满足
横向对齐和无碰撞在该模型几何下不可行。实现因此保留横向对齐，并沿真实滑轨
向外选择首个无碰撞位置；烟雾门改为距离不超过 0.43 m、横向误差不超过
0.01 m，且不得存在底座—抽屉接触。严格抓取、接触、运输、释放和最终支撑
谓词均未改变。

## 目标

修复 VLA82-037 抓取夹子前底盘斜向追逐目标、推动打开抽屉并使夹子同步移动的问题。机器人应在 reset 阶段停靠到抽屉正面安全位置，仅由机械臂接近并抓取夹子。

## 已确认根因

新资产已经能在约 22 秒内正常加载，但完整物理复测在 `reach_base` 阶段结束：

- 抽屉滑轨世界方向为 Y 轴；
- 初始底盘为 `(1.651, -0.943)`，夹子为 `(1.928, -0.584)`；
- 底盘同时沿抽屉宽度和滑轨方向追逐夹子；
- 底盘靠近时推动打开的抽屉，夹子随抽屉沿 Y 方向移动；
- 95 步内距离仅从约 `0.453 m` 变为 `0.441 m`，无法进入 `0.39 m` 的机械臂可达范围。

问题不是距离阈值过严，而是初始底盘没有沿抽屉宽度与物体对齐。

## 方案

### 1. 基于真实滑轨轴计算对齐方向

从 MuJoCo 读取抽屉 slide joint 的局部轴，并通过关节所属刚体的世界旋转矩阵转换为世界滑轨轴。滑轨轴表示抽屉的前后运动方向；与其正交的水平轴表示抽屉宽度方向。

不通过 fixture 名称、固定 X/Y 假设或 selection ID 推断方向，以支持旋转后的厨房布局。

### 2. 仅在 reset 阶段做宽度方向对齐

使用 RoboCasa 已采样的三个真实位置：抽屉中心、原生底盘锚点和夹子中心。

- 保留底盘在滑轨轴上的原生投影，因此与打开抽屉的前后安全距离不变；
- 仅修改底盘在抽屉宽度方向的投影，使其与夹子中心对齐；
- 保持底盘高度和朝向不变；
- 关闭 reset 随机位置与旋转偏差；
- 不修改夹子、抽屉、关节或其他物体的状态。

在 seed 2000 场景中，预计底盘与夹子的水平距离由约 `0.453 m` 降为约 `0.359 m`，低于现有 `0.39 m` 阈值。

### 3. 抓取前禁止底盘追逐

对于权威语义为 `source_fixture == "drawer"` 的取放任务，控制器从机械臂 `approach` 阶段开始，不进入 `reach_base`。该行为由场景语义选择，不使用单一对象编号特判。

机械臂仍按现有闭环执行接近、下降、双指接触、夹紧、抬升、运输和台面释放。若 reset 后目标仍超出 `0.39 m`，场景预检直接失败，不允许控制器重新启用底盘追逐。

## 方案边界

- 不提高 `0.39 m` 可达阈值；
- 不增加运行时底盘路径；
- 不关闭底盘与家具碰撞检查；
- 不改变抽屉初始开合状态；
- 不直接写入 MuJoCo qpos、物体位姿或成功状态；
- 不修改严格接触、阶段、运输、释放和最终台面支撑谓词；
- 不影响柜体取物、台面到抽屉放置或其他非抽屉源任务。

## 测试

### 纯函数测试

- 滑轨法向投影在对齐前后保持不变；
- 底盘与物体在宽度方向的误差对齐到数值容差内；
- 高度与其他非平移分量保持不变；
- 无效或零长度滑轨轴必须快速报错。

### 场景语义测试

- VLA82-037 被识别为抽屉源任务；
- 抽屉源任务安装 reset 对齐钩子；
- 抽屉源任务的初始控制状态为 `approach`；
- 台面到抽屉、柜体到台面等现有任务保持原控制状态。

### 环境烟雾测试

使用 seed 2000 加载 VLA82-037，验证：

- 底盘与夹子的初始水平距离不超过 `0.39 m`；
- 底盘在真实滑轨方向上仍位于原生安全侧；
- reset 后任务并未预先完成；
- 抽屉、夹子和底盘没有初始穿透接触。

### 完整物理复测

回归测试全部通过后仅运行一次 VLA82-037：

1. 抓取前底盘无平移动作；
2. 机械臂真实接触并夹持夹子；
3. 夹子离开抽屉且运输中不脱落；
4. 夹子在台面上稳定释放；
5. 严格阶段、接触和最终状态谓词全部通过。

只有严格 PASS 才生成高清无遮挡视频并更新 Excel。

## 失败与停止条件

- 若环境烟雾测试中的初始距离仍大于 `0.39 m`，停止完整仿真并检查滑轨世界轴转换；
- 若底盘或机器人在 reset 后与抽屉发生穿透，停止并调整切向对齐实现，不缩短前后安全距离；
- 若首次完整物理复测失败，保留诊断结果并分析首个机械臂动作阶段，不立即重复运行；
- 严格 FAIL 时不生成结果视频、不更新严格 PASS 汇总表。
