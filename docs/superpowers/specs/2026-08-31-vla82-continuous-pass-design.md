# VLA82 连续视频修复与新增严格 PASS 设计

## 目标

先修复 VLA82-055 在 1.5–10 秒间的长时间迟滞，保留真实 MuJoCo 物理闭环；随后从未通过项目中选择一个操作语义明确、场景可达且适合快速完成的对象，优化其外观并新增一项严格 PASS。

## 方案比较与选择

1. 仅加速视频：最快，但不消除控制轨迹中的真实迟滞，不采用。
2. 放宽所有任务的到位阈值：可能影响其他对象，不采用。
3. 为 VLA82-055 使用与置物架释放门限一致的专用搬运到位阈值，并重新执行物理仿真：改动最小且保留真实动作，采用。

新增对象不按编号顺序硬做，而是先核对 `operation_specs.json`、原始标注路径、目标设施和现有失败轨迹，再选择成功率最高的候选。外观模型必须具有能辨认类别的主体结构、颜色和关键部件；碰撞几何保持简洁且与视觉外形一致。

## 判定

- VLA82-055：控制轨迹不再在目标附近反复振荡；仍满足释放倾斜/偏航均不超过 5°、目标接触、无夹爪碰架、最终稳定。
- 新对象：操作与标注语义一致，目标设施正确，完整经历接近、抓取/接触、搬运或设备动作、完成状态；严格判定 JSON 为 PASS 且 `predicate_success=true`。
- 两项均输出 1280×720 正向无遮挡视频；新增物体的视频和 JSON 保存至 `C:\OpenVLA-Simulator\datasets\VLA82 video`。

## 自检

设计无占位项；“操作语义确认—外观优化—物理执行—严格验证—正式归档”的顺序明确，不使用瞬移或仅脚本宣称成功。
