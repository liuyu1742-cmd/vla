# OpenVLA / OpenVLA-OFT 仿真实验复刻设计

## 目标与验收

在本项目现有的 OpenVLA、LIBERO 和 RoboCasa 资产上复刻第 4.6 节，排除真实机械臂实验。所有结论必须由本地运行日志、模型元数据或明确标注的官方公开结果支持。成功率验收线为用户给定表格数值减 5 个百分点；若低于该门槛，则在不改变评测判据的前提下调节官方支持的推理或训练参数并重新评测。

## 已确认约束

- 硬件为单张 NVIDIA GeForce RTX 3090（24 GB）。
- 允许使用微批次和梯度累积，使有效 batch size 为 16。
- 项目已有 OpenVLA-7B、一个 LIBERO-Goal 微调检查点、LoRA 家庭任务适配器和官方风格的 LIBERO 纯策略评测器。
- 项目尚未部署 OpenVLA-OFT；本地纯 OpenVLA 家庭任务闭环并未达到可用于高成功率对比的水平。
- OpenVLA-OFT 官方训练最低需要约 25.6 GB（batch size 1，bf16），完整 LIBERO 配方使用 8 张 80 GB GPU，因此本机不声称重新训练完整 OFT。
- LIBERO 官方第四个套件是 `LIBERO-Long`，不是 `LIBERO-Navigation`。最终章节采用官方名称并说明修正。

## 方案比较

### 方案 A：官方 OFT 检查点本地复评 + 项目微调资源实测（采用）

使用 OpenVLA-OFT 官方代码和公开 LIBERO 检查点，在本机 LIBERO 仿真环境中运行纯策略闭环；OpenVLA baseline 复用项目已有官方协议日志，并按需补充官方公开结果。微调方法表在同一 OpenVLA-7B 架构上计算可训练参数，并以微批次/梯度累积配置做显存探测；无法在 24 GB 完成的配置记录为实测 OOM，同时给出官方多卡参考值。成功率仅填写实际闭环结果或明确标注的官方复现值。

优点是 OFT 方法、动作块、连续动作头和 L1 损失均与官方一致，且本机能完成推理验证；缺点是不能把完整 OFT 的 8×80 GB 训练冒充为单卡复现。

### 方案 B：单卡重新训练全部方法与 OFT

对 Full Fine-tuning、LoRA、Last Layer Only、Frozen Vision 和完整 OFT 全部从头训练。该方案理论上最完整，但全参数训练与 OFT 的最低显存均超过本机能力，CPU offload 在 Windows 环境下风险高、耗时不可控，也无法在合理实验周期内达到论文训练步数。

### 方案 C：仅转录论文表格

直接采用论文结果，不运行本地仿真。成本最低，但不构成项目复刻，因此不采用。

## 实验构成

### 实验 1：OpenVLA 微调方法对比

统一基础模型、5-shot 项目示教清单、图像尺寸、有效 batch size 16 和评测判据。四种参数模式如下：

1. Full Fine-tuning：视觉编码器、投影器和语言模型全部可训练。
2. LoRA (rank=32)：冻结基础权重，对线性层注入 rank 32 LoRA。
3. Last Layer Only：仅训练最后语言层及动作输出相关层。
4. Frozen Vision：冻结视觉编码器，训练语言与动作相关模块。

对每种模式记录可训练参数量、一次训练步的峰值显存或 OOM、配置摘要和证据路径。若完整闭环训练因硬件不可执行，成功率列不伪造；采用与项目兼容的已完成检查点或官方同方法结果时，必须在表注中注明来源。

### 实验 2：OpenVLA-OFT 性能评估

使用官方 `moojink/openvla-oft` 代码和公开检查点，配置保持：

- 并行解码；
- action chunking（LIBERO chunk size 8）；
- 连续 7 维动作表示；
- MLP action head；
- L1 回归目标；
- 第三人称图像 + 腕部图像 + 本体状态（检查点要求时启用）；
- 无专家恢复、无规则伺服替代策略。

按 Spatial、Object、Goal、Long 四套件运行。先做单回合 smoke，再按固定初始状态进行正式评测，保存逐回合成功布尔值、错误、动作决策数、推理延迟和汇总成功率。若完整 400 回合运行时间过长，可先完成每套件覆盖全部 10 个任务的分层评测，并在报告中准确写明每任务回合数。

OpenVLA baseline 与 Diffusion Policy 列若未在本机获得相同检查点，则采用原论文/官方基准数值并标注“官方报告”；不把不同任务或混合控制结果填入这两列。

### 实验 3：OFT 消融

不以手工后处理模拟训练消融。优先使用官方发布的消融检查点或论文表格，覆盖：

- 自回归离散动作；
- 并行解码/动作块；
- 连续动作表示；
- L1 回归。

若官方未发布对应检查点，则在正文中将其明确写为官方消融结果，不称为本机实测。
