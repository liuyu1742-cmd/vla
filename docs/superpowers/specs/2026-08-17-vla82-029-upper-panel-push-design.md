# VLA82-029 把手上方宽门板推压设计

## 1. 目标与依据

VLA82-029 已经能够完成微波炉门自由边绕行并进入正确关门侧，但现有返回路径会先撞到突出把手或门板边缘。最新物理轨迹中的 80 帧接触全部来自 `gripper0_right_hand_collision`：41 帧接触 `door_handle_main`，40 帧接触 `door_main`；最大连续接触仍为 1 帧。实时法向补偿无法解决接触点本身不适合持续推压的问题。

本轮目标是在保留已验证自由边跨面路径的基础上，使机械手从把手上方接近门板宽平面，在远离把手和上下边缘的位置建立真实接触，再沿铰链闭合切向持续推门。

## 2. 目标几何体选择

从微波炉门关节绑定的可碰撞几何体中选择宽门板碰撞盒：

1. 排除名称包含 `handle` 的几何体。
2. 仅考虑 MuJoCo box 几何体。
3. 对每个候选计算三个半尺寸；最小半尺寸视为厚度，另外两个尺寸的乘积视为门板面积。
4. 选择“厚度最小、门板面积最大”的候选作为 `panel_geom`。
5. 将语义门板 `door_main` 与 `panel_geom` 共同作为允许的宽门板接触集合；把手、上边框、下边框和其他门体附件不得触发 `push_close`。

当前场景中预期选择 `microwave_main_group_1_g12`，其记录半尺寸约为 `[0.234, 0.0028, 0.165] m`，符合薄而宽的门板碰撞盒特征。选择必须依据实时模型属性，不硬编码该名称。

## 3. 上半部门板目标点

使用 `panel_geom` 的实时世界坐标中心、旋转矩阵和半尺寸计算目标：

- 法向轴：半尺寸最小的局部轴。
- 竖直轴：剩余两轴中世界 Z 分量绝对值较大的轴，并统一为正 Z 方向。
- 水平轴：另一个门板平面轴。
- 上半部偏移：沿正竖直轴移动门板半高度的 `45%`。
- 水平位置：保持门板水平中心，不向自由边或铰链侧偏移。

门板表面接触点位于运动方向后侧表面：

`panel_face = panel_center + 0.45 × half_height × vertical_axis - push_direction × projected_half_thickness`

预接触点为：

`panel_precontact = panel_face - push_direction × 0.06 m`

该位置应高于把手中心至少 `0.07 m`，同时与门板顶部保留至少 `0.08 m` 的夹爪安全余量。若实时尺寸不能同时满足把手避让和顶部余量，几何检查失败，本轮不盲目运行物理仿真。

## 4. 路径状态机

保留现有 `bypass_to_free_edge` 和 `bypass_cross_plane`。跨面完成后，以锁存的门板目标执行：

1. **raise_above_handle**：在自由边轮廓之外、正确关门侧，将夹爪接触参考点竖直移动到 `panel_precontact` 的高度。此阶段不得触碰门体或把手。
2. **traverse_to_upper_panel**：保持目标高度和正确侧距离，沿门板水平方向移动到上半部门板预接触点。此阶段若接触把手或边框，立即停止前进并回到抬升点，不得将其视为有效门板接触。
3. **seat_upper_panel**：沿 `push_direction` 低速靠近 `panel_face`，仅当允许的宽门板几何体与夹爪或掌部产生真实 MuJoCo 接触时进入推门阶段。
4. **push_close**：以实时铰链闭合切向为主方向短步推送。若宽门板表面法向已经与切向同向，法向补偿为零；只有出现小幅离面分量时才使用已实现的受限法向补偿。
5. **reseat_upper_panel**：短暂失去宽门板接触后，沿最后有效门板法向重新贴合 `0.006 m`，不得返回把手区域或自由边路径。
6. **settle_closed**：进入现有严格关闭阈值并稳定保持后结束。

路径点在完成跨面时锁存，避免控制周期内漂移；门开始转动后，只实时更新关门切向和接触法向。

## 5. 工具姿态与底盘

- 沿用自由边绕行结束时已经完成的工具姿态，不在靠近门板时进行大角度重新定向。
- 夹爪保持闭合，使掌部和夹爪形成紧凑、稳定的推压端面。
- 整个抬升、横移、贴合和推门阶段保持底盘固定。
- 控制器继续通过正常 PandaOmron 动作向量运动，不写关节位置或门体姿态。

## 6. 碰撞与回退

- `raise_above_handle` 或 `traverse_to_upper_panel` 阶段出现任何门体接触，视为提前碰撞，不允许进入 `push_close`。
- 若提前接触对象为把手或上边框，记录接触对象、位置、法向和目标高度。本轮只允许根据该证据提高抬升目标一次，且仍需保持顶部 `0.08 m` 余量。
- 若提高后仍碰撞，停止该路径，不反复提高高度；转而评估靠近铰链侧的宽门板目标。
- `seat_upper_panel` 只接受宽门板集合中的接触。把手接触、边框接触或单帧擦碰不构成有效贴合。
- 若连续接触形成但铰链角不向零变化，检查实际接触点力臂和合成方向，不增加全局推力。

## 7. 组件边界

新增纯几何组件：

- `fixture_close_panel_geom_name(...)`：从关节绑定候选中选择薄而宽的门板 box。
- `fixture_close_upper_panel_waypoints(...)`：计算抬升点、横移预接触点和门板表面点，并验证把手与顶部余量。
- `fixture_close_upper_panel_stage(...)`：按完成标志、宽门板真实接触和关闭状态选择阶段。

`DrawerClosePrimitive` 负责读取实时模型、锁存路径点、区分宽门板接触与附件接触、执行正常动作并记录轨迹。该路径只对 VLA82-029 的微波炉铰链关闭启用，不改变其他物体和家具控制器。

## 8. 测试策略

先通过 TDD 验证纯函数：

1. 在包含门板、把手和边框的候选中选择薄而宽的非把手 box。
2. 门板旋转后仍能正确识别世界竖直轴、法向轴和上半部目标。
3. 抬升点位于自由边外侧且与横移点同高。
4. 门板接触点高于把手，并满足顶部 `0.08 m` 余量。
5. 不满足几何余量时明确抛出错误，不生成危险路径。
6. 状态机必须完成抬升、横移和宽门板真实接触后才能 `push_close`。
7. 把手或边框接触不得触发推门。
8. 非微波炉关闭任务不得启用该路径。

随后运行全部现有单元、闭环和谓词回归。回归通过后只运行一轮 VLA82-029 新鲜物理仿真，并比较宽门板接触对象、连续接触长度和铰链角变化。

## 9. 轨迹证据

每帧记录：

- 选择的 `panel_geom`；
- 门板中心、旋转、半尺寸；
- 抬升点、预接触点和表面接触点；
- 三个路径完成标志；
- 当前阶段；
- 实际门体接触对象；
- 是否属于允许的宽门板接触；
- 连续宽门板接触帧数；
- 实时关门切向、法向补偿和最终方向；
- 铰链角及严格关闭阈值。

## 10. 严格 PASS 条件

VLA82-029 只有同时满足以下条件才可纳入严格 PASS：

- 自由边跨面、上方抬升和横移均通过正常物理动作完成，无穿模或状态瞬移；
- 推门阶段的有效接触来自宽门板，而不是突出把手或上下边框；
- 连续宽门板接触明显超过此前 1 帧上限；
- 接触产生正确关门力矩，铰链角持续向 `0 rad` 变化；
- 门体达到现有严格关闭阈值并稳定保持，无明显回弹；
- JSON、NPZ、谓词、接触轨迹和无遮挡高清视频内容一致。

未满足全部条件时仍标记 FAIL，不生成严格 PASS 视频，不更新汇总表。
