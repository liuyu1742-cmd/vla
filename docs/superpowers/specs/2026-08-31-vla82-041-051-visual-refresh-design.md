# VLA82-041 与 VLA82-051 外观增强设计

## 目标

在不改变既有严格 PASS 操作语义的前提下，提高 VLA82-041 汤勺、VLA82-051 铅笔及实体笔盒在仿真视频中的可辨识度。重新生成两项严格 PASS 轨迹、720p 正向无遮挡视频与判定 JSON，最终替换 `C:\OpenVLA-Simulator\datasets\VLA82 video` 中对应的旧文件。

## 设计选择

采用“可视几何增强、物理几何保持不变”的方案。不导入外部网格，不依赖网络纹理，不改变已验证的碰撞包络、注册尺寸、质量载体、摩擦力或任务场景。

### VLA82-041 汤勺

- 使用扁椭圆体表现勺碗，并增加内凹暗色层以形成容器轮廓。
- 使用短勺颈连接勺碗和细长圆柱勺柄。
- 使用银灰色分层材质和窄高光条表达金属表面。
- 保留原有水平放置方向、注册包围盒和单一碰撞体，避免影响台面抓取、搬运及抽屉放置。

### VLA82-051 铅笔

- 使用黄色细长笔身，并用多条窄色带形成六棱木杆的视觉印象。
- 增加削尖木段、黑色石墨笔芯、金属箍和红色橡皮。
- 保留原有细杆碰撞包络、尺寸和质量属性，避免改变双夹持垫抓取策略。

### VLA82-051 实体笔盒

- 使用蓝色底板和四周实体壁构成开放式笔盒。
- 增加浅色内衬、上沿边框和拉链装饰，提高“笔盒”而非普通盒子的辨识度。
- 顶部必须保持开放，目标内部空间和内底接触必须可见。
- 保留现有五面开放容器碰撞结构及目标区域定义，不缩小铅笔可插入空间。

## 数据流与替换流程

1. 为三类资产增加可辨识视觉部件，并用自动测试检查部件名称、碰撞数量、注册尺寸和质量载体。
2. 在独立输出目录重新采集 VLA82-041、VLA82-051 专家轨迹。
3. 只有 `status=PASS` 且 `predicate_success=true` 的回合才进入视频生成。
4. 生成 1280×720、正向无遮挡视频，抽帧检查物体、抓夹和目标区域是否可见。
5. 检查新 MP4、严格判定 JSON 和 NPZ 后，删除归档目录中的旧 MP4 与旧 JSON。
6. 将新 MP4 与新严格判定 JSON 移动到旧文件原位置和原文件名，保持集中归档索引路径有效。

## 错误处理与安全边界

- 新轨迹未严格 PASS：保留旧归档文件，继续针对失败状态调整，不提前删除。
- 新视频不可解码、低于 1280×720、画面倒置或操作被遮挡：不替换旧文件。
- 替换前记录旧文件哈希；删除仅限 041、051 的四个明确路径，不使用通配递归删除。
- 移动完成后重新验证目标文件哈希、JSON 状态、视频帧数和原临时源文件是否消失。

## 验收标准

- 汤勺可清楚辨认出勺碗、勺颈和勺柄。
- 铅笔可清楚辨认出笔身、木质削尖段、笔芯、金属箍和橡皮。
- 笔盒为开放式实体容器，四壁、内底、边框和装饰可见。
- 两项均重新取得严格 PASS，视频为 1280×720、正向无遮挡且可正常解码。
- 归档目录中每项仅保留一个最终 MP4 和一个最终严格判定 JSON；旧文件已删除，新文件使用原归档文件名。
