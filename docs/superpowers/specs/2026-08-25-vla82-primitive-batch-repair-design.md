# VLA82 操作原语批量修复设计

## 目标

将 VLA82 剩余物体的严格仿真验证从逐项盲跑，改为按操作原语复用经过验证的场景初始布局和控制路径。

## 边界

- 允许在 RoboCasa 重置前配置正常的物体初始位置、朝向和门的初始开启角度。
- 不在运行过程中写入物体位置、门关节最终值或判定结果。
- 严格 PASS 仍要求机器人通过 `env.step` 产生真实抓取/接触/关节运动，并满足最终谓词。

## 原语

1. 开放支撑面放置：物体在可达的同一支撑面区域，目标为明确的开放台面区域。
2. 抽屉放置：对象以与抽屉开口平行的初始姿态配置，目标为抽屉内底面。
3. 门体关闭：门以合理开启角度开始，机器人从可接近的把手/面板侧完成关闭。
4. 清洁：工具从可达支撑面开始，接触并覆盖目标清洁区域。

## 验证

每个原语先用一个代表对象在固定种子下验证，再复用于同类对象。仅当物理接触、最终谓词和无遮挡视频均通过时，才更新严格 PASS 索引。
