# VLA82-018 连续抓取严格判定设计

## 问题

VLA82-018 的旧轨迹出现三段彼此分离的抓取：前两次在橱柜抽取阶段滑脱，第三次移出后再次滑脱。物体随后落到目标台面，位置谓词将其误判为受控放置；控制器轨迹实际从未进入 `release` 或 `settle`。

## 设计

严格判定增加控制轨迹质量门：放置类操作必须存在一次连续的有效抓取，抓取后至释放前不得发生持续丢失并重新抓取，并且必须明确进入 `release` 和 `settle`。最终位置正确但没有受控释放阶段时一律失败。

橱柜抽取控制使用现有的连续帧丢失确认机制。单帧或短暂的原生抓取信号抖动期间继续保持夹紧和原抽取方向；只有连续三帧确认失去抓取后才返回重抓。严格结果仍不接受发生过真实重抓的轨迹。

## 验收

- 旧 VLA82-018 轨迹被新门禁稳定拒绝。
- 正常的一次抓取、连续搬运、`release → settle` 轨迹通过门禁。
- 全新仿真视频中仅出现一次抓取，物体全程不掉落，最终平稳放至台面。
- 视频为正向 1280×720 或更高、无遮挡、完整解码；视频和 JSON 仅在全部检查通过后移入 `datasets/VLA82 video`。
