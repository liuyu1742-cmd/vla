# VLA82-016 书籍放至床头柜设计

## 目标与权威语义

VLA82-016 的唯一权威操作来自
`datasets/chapter5_5_2_8_物品递送/书籍/operation.json`：
“从床边取用并放至床头柜”。仿真必须表现为书籍从一个开放起点被抓起、连续搬运，并稳定放在一个可见、可接触的实体床头柜支撑面上。

## 方案选择

采用专用卧室场景，而不沿用旧的 `PickPlaceCounterToCabinet` 或桌面替代场景。后者分别把“床头柜上”错误解释为“橱柜内部”或把床头柜摆在工作台上，均不符合权威操作语义。

书籍使用普通闭合硬皮书外形：矩形封面、纸页、书脊和封面标签全部位于物体外轮廓内，只有一个与可见外形一致的矩形碰撞体。尺寸缩放为夹爪可处理的 130×70×30 mm；这是仿真尺度调整，不增加凸起、隐藏把手或非真实抓取结构。

环境使用房间地面和墙面，实体床包含床架、床垫、床头板、枕头与毯子，书籍出生点绑定床垫顶面。目标使用直接落地的固定木质床头柜模型，包含柜体、顶板、抽屉面板和把手视觉结构；严格支撑接触绑定到柜体顶面。床头柜位于床右侧，二者在审计相机中同时清晰可见。

## 控制与判定

控制器先将夹爪开口轴与书籍短边对齐，再从上方下探，使双指位于书籍两侧并闭合；随后抬升、连续搬运、降低到床头柜顶面、受控释放并稳定保持。

严格 PASS 必须同时满足：双指垫真实接触、原生抓取成立、搬运距离达到阈值、目标顶面精确接触、受控释放、连续稳定帧、最终无明显滑动。视频必须为正向 1280×720，书籍、床头柜、夹爪和完整操作区域无遮挡。

## 失败处理

若失败，先按轨迹状态、接触法向和最终位置定位到场景语义、几何可达、夹持、搬运或释放中的具体阶段；每次只验证一个根因假设。若该架构连续三次针对性修复仍暴露新的结构性限制，则切换下一候选，不进行无意义重复。

## 自审

文档无占位项；操作、物体、目标、控制阶段和严格判据一致；范围仅覆盖新增 VLA82-016 严格 PASS 及证据归档。
